# Stitch prompts (generate each at mobile and desktop where noted)

**Style (add to every prompt):** Modern, warm and clean hospitality app. Warm off-white background, deep green primary, terracotta accent, rounded cards, large touch targets, friendly sans-serif. Brand name: Tafole.

1. **Guest menu (mobile):** Restaurant menu opened from a QR code. Header shows restaurant name and "Table 7". Category chips, item cards with photo, name, price and an add button, sticky cart bar at the bottom.
2. **Guest cart and order status (mobile):** Cart with quantities and notes, submit button, then a live status tracker (Received, Preparing, Ready) and persistent "Call waiter" and "Request bill" buttons.
3. **Waiter table view (mobile and tablet):** Grid of tables with colour-coded status (empty, ordered, waiting, bill requested), open requests list sorted by wait time, tap a table for order details and actions.
4. **Kitchen display (tablet landscape):** Kanban columns New, Preparing, Ready with order tickets grouped by table, timers and big status buttons.
5. **Manager menu editor (desktop):** Table of menu items with category sidebar, edit drawer with price, photo and sold-out toggle.
6. **Manager tables and QR (desktop):** Tables list with seats, generate and print QR code per table.
7. **Manager dashboard (desktop):** Orders per day, median response time, busiest hours chart, staff list.
8. **Staff login (mobile and desktop):** Simple email and password login with Tafole branding.
